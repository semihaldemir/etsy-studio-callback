ETSY STUDIO

Bağlantı sayfası hazır

Bu adresi Etsy uygulamanızın Callback URLs alanına ve masaüstü uygulamasındaki callback alanına aynı şekilde kaydedin. Ardından yetkilendirmeyi masaüstü uygulamasından başlatın.

  1. Etsy Studio uygulamasına dönün.
  2. Bağlantıyı “Tam callback URL” alanına yapıştırın.
  3. “Bağlantıyı tamamla” düğmesine basın.

Bu sayfaya API anahtarı veya Shared Secret girmeyin. Sayfa Etsy tarafından üretilmemiştir; yetkilendirme sonucunu masaüstü uygulamasına taşımanıza yardımcı olur.
